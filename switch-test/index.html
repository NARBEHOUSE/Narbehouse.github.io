Switch test

This page shows what your switches send to a web page, so we can set them up in Benny's Hub.

  1. Press switch 1 a few times, then hold it for about 3 seconds.
  2. Press switch 2 a few times, then hold it for about 3 seconds.
  3. Try it with Apple Switch Control turned OFF, then again with it turned ON (Settings > Accessibility > Switch Control). Each time, set the button below to match.
  4. Tap Copy results and send them to Ari.

Your results stay on this page if you leave to change settings. Nothing is sent anywhere until you copy it and send it yourself.
