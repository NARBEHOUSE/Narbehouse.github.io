ONE-TIME SETUP

Get your Trinkey ready.

Use this once for a Trinkey with the original NARBE switch software. This site handles the update and saves a recovery copy in this browser. No manual downloads or file copying.

Keep just one Trinkey plugged in. Setup replaces its device software and starts with Space and Enter.

  1. Show the setup drive.

    Quickly press the small reset button twice. A drive named TRINKEYBOOT or TRRSBOOT will appear.

    Show Adafruit's reset-button instructions ↗
  2. Let this site prepare your Trinkey.

    Select that BOOT drive. We'll check the model, save its original software, and send the update. Keep it plugged in while the drive disappears and returns as CIRCUITPY.

  3. Finish setup.

    When CIRCUITPY appears, select it below. We'll install and check the remaining files.

  4. Reconnect and make it yours.

    Wait for the completion message. Eject CIRCUITPY, then unplug and reconnect the Trinkey. Close this guide and click Connect your Trinkey. Future visits start there.

Already using CircuitPython? Install or repair setup files

For a TRRS Trinkey already running CircuitPython 10.x: press reset once, then again during the yellow startup blink (within about one second). This slower sequence opens safe mode. Look for CIRCUITPY and repeating yellow blinks.

Restore original device software

Recovery copies stay in this browser on this website. Choose the copy for this unit, double-press its reset button, then select its BOOT drive. This restores its earlier software and bindings.

Clearing browser data or switching browsers/websites removes access to these stored copies. You can keep an optional copy after setup.
