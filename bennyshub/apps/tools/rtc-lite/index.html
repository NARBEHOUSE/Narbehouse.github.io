AI suggestions

Free AI recommendation: use desktop Chrome. Open RTC Lite in Google Chrome on a supported computer. Choose Chrome local AI · Gemini Nano, then Load AI model. No API key or per-request charge. A model download and compatible hardware are required.

Gemini Nano is unavailable to this website on Android, iPhone and iPad, including Chrome’s “Desktop site” mode.

Your own cloud API key and local server AI (Ollama or OpenAI compatible) remain available. Cloud AI receives conversation text and your profile; fees or quotas may apply. AI Off keeps saved phrases and dictionary words available.

Local AI server

Run Ollama or an OpenAI-compatible server on this computer. Install a model in that server first. RTC Lite sends conversation text to the address below; your cloud API key is never sent here. For offline use, choose a downloaded local model in your server.

Ollama default: http://127.0.0.1:11434. LM Studio commonly uses http://127.0.0.1:1234. If the server blocks this page, allow this page’s origin in the server’s CORS settings.

Connect your own cloud AI

Connect OpenAI, Anthropic, or Google Gemini through Benny’s Hub key service. Key setup opens a separate window and may require help typing or pasting your key. Your key is encrypted in Cloudflare storage for up to 30 days; this app keeps only a revocable connection token. The Worker and AI provider receive your bio and conversation text for suggestions. Cloud usage may cost money.

Local speech recognition remains separate. Disconnect stops this app’s access. To delete a provider key for all connected apps, open key setup and choose Remove. Existing browser keys are never uploaded automatically.
