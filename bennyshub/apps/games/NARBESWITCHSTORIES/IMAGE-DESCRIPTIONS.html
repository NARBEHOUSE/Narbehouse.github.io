Switch Stories: image descriptions

This chart supplies the descriptions used by the game. Click a description cell to edit it, then choose Save document. Save it as IMAGE-DESCRIPTIONS.html in the Switch Stories folder, replacing this file. Reload the game to use the saved wording. Unsaved edits are not used by the game.

If your browser downloads the file instead of offering a folder, move that download into the Switch Stories folder and replace this file. You can also edit the table text directly in your code editor. Keep the story IDs, page numbers, and data-field attributes unchanged.

When Image Descriptions is on: image description → switch press → story passages → switch action → action description → switch press to turn the page. Longer descriptions split into short passages. Descriptions speak only when Read Aloud is on. If animations are off, action descriptions are skipped.
