Developer / tester preview: manual installation

Loading an unpacked extension is a development and testing feature. Only load code you trust. This download does not install anything automatically or provide store approval.

Download Companion 1.0.2 ZIP for testing

  1. Extract the ZIP into a folder you will keep. Find manifest.json directly inside that folder; do not select the ZIP itself.
  2. In a new tab, type chrome://extensions for Chrome or edge://extensions for Microsoft Edge.
  3. Turn on Developer mode, choose Load unpacked, and select the extracted folder containing manifest.json.
  4. Open Benny's Hub in the same browser profile and refresh it. This packaged preview connects only to that public Hub address, not localhost or a file opened from your computer.
  5. Return to this setup page. Once it says Connected, open Companion settings and grant access only to the sources you want to test.

Updates are manual: download and extract the newer package into the same folder, click Reload on the extension's card, then refresh the Hub. Close old streaming windows and launch a new stream. Changing files on our website does not update your installed preview.

To stop testing: turn the extension off or choose Remove on its card. Uninstalling removes its settings; Hub data is separate. When store installation is available, export important Hub data and remove the unpacked copy before installing the store version. Source permissions and Companion settings may need to be set again.

If your browser or organization blocks developer extensions, wait for the store release. Do not disable browser security protections or change organization policies to install this preview.

Streaming controls & keyboard access

Space scans forward. Hold Space to scan backward. Enter selects. In one-switch mode, Enter starts one scan loop; the bar rests after a selection or a complete loop. Return to Hub is always last.

Clicks on the movie keep the bar in control. For signing in or typing, use Alt+Shift+B to temporarily allow the website's keyboard and mouse controls. Press it again to return to the bar.

The video fills the playback window automatically when it becomes available. Service compatibility is still experimental.
